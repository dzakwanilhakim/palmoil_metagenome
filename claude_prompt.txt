BRONZE:

- "No/Kode Sampel" {224, 225, 1, ...), 
- "Nama Sampel" {PAS-PHN10-T1-07-SSUM,  AT-PH3-T1-08-SSUM, TPP-OL0002-PH1-T0-06-SSUM, ...},,
- "Jenis Kebun" {Nursery,TM},

- "Batch Ekstraksi" {9 (31/07/2026), 8 (08/07/2026)},

Silver:
4. Process:
- Filter out rows if "Batch Ekstraksi" is empty or NA
- Make df$"Batch Ekstraksi" and df$Date Ekstraksi from "Batch Ekstraksi", example 9 (31/07/2026) to batch 9 and date 31/07/2026, convert to format YYMMDD

5. QC Per Column
-"No/Kode Sampel":  make sure there is no NA, empty, and duplicate, and integer only
-"Nama Sampel": make sure there is no NA, empty, and duplicate
-"Jenis Kebun": make sure there is no no NA, empty, only 2 unique, Nursery or TM
-"Jenis Analisis": make sure there is no no NA, empty, only 3 unique, 16S, ITS, 16S + ITS
-"Batch Ekstraksi", "Data Ekstraksi" : make sure there is no no NA, empty

6.Create column "Kode Kebun": retrieve all character from first underscore character "_" from "Nama Sampel", ex GSDI-PHN04-T0-06-SSUM the Kode Kebun is GSDI, 
7.Create column "Kode Pupuk": retrieve all character if the regex pattern is "-PHX-" or "-PHNXX-" from "Nama Sampel, ex AMR-PH1-T2-06-SSUM, GSDI-PHN12-T2-05-SSUM, and TPP-OL0002-PH1-T0-06-SSUM, the kode pupuk respectively is  PH1, PHN12 and PH1, if there was no kode kebun like -PHN- or -PH- or dont have the pattern, just set NA and give warning "2 sample dont have Kode Kebun"
8.Create column "Waktu": retrieve all character if the regex pattern is -TX- from "Nama Sampel", ex AMR-PH1-T2-06-SSUM, GSDI-PHN12-T2-05-SSUM, and TPP-OL0002-PH1-T0-06-SSUM, respectively is T2, T2, T0. if there was no Waktu like -T- or dont have the pattern, just set NA and give warning "2 sample dont have Waktu"
9.Create column "16S" and "ITS". from "Jenis Analisis" set 0 for absence, or 1 for presence analysis. like IF 16S in jenis analisis so 1 for 16S and 0 for ITS vice versa,if 16S + ITS set 1 and 1 for both 16S ITS
10. Split to metadata_16s and metadata_its
11. output data/silver/silver_metadata_16s.csv and data/silver/silver_metadata_its.csv
